Choisis les réglages, puis copie le lien et donne-le à tes élèves. Les réglages sont portés par le lien lui-même : rien n'est stocké sur un serveur et rien n'est protégé (un élève curieux peut modifier son propre lien).

Imposer des séries à un élève (facultatif)

Le lien obtenu est personnel : nom et exercice sont figés, l'élève doit réussir le nombre de séries demandé, chacune avec au moins la note minimale (une série en dessous ne compte pas et est à refaire). Chaque série est enregistrée dans la feuille avec la mention « Série imposée ». Laisser le prénom et le nom vides pour un lien ordinaire.

Remettre à zéro

L'historique, les notes mises de côté, le nom mémorisé et les séries imposées sont gardés dans le navigateur de chaque élève (et dans le tien pour tes essais). Ce bouton efface ceux de cet appareil seulement. Pour vider la feuille Google, supprimer ses onglets « Notes V3 … », « Journal V3 … » et « … validées » : le script les recrée au prochain envoi.

Changer le mot de passe

Saisis le nouveau mot de passe : la page calcule la ligne à coller dans le code (à la place de la ligne const MDP=…). Le mot de passe lui-même n'est pas stocké.
